# مخزون البودرة

## فتح نسخة الهاتف

افتح التطبيق من الهاتف عبر [رابط GitHub Pages](https://mahmoudalmorsi.github.io/powder-inventory-mobile/).

نسخة Pages تحفظ البيانات في متصفح الجهاز فقط ولا تشارك التعديلات مع نسخة الكمبيوتر أو أجهزة أخرى، ولا توفر تسجيل دخول. قراءة الاستيكر OCR تتم محلياً داخل المتصفح ولا ترسل الصور إلى خادم؛ يلزم اتصال بالإنترنت لتنزيل محرك القراءة وبيانات اللغة عند الاستخدام. استخدم أزرار تصدير واستيراد النسخة الاحتياطية لنقل بيانات هذا الإصدار يدوياً.

## تشغيل النسخة المشتركة

واجهة الخادم التي تستخدم قاعدة بيانات مشتركة موجودة في `mobile/`، وتحتاج إلى استضافة خادم Python مع قاعدة بيانات دائمة. إرشادات Railway موجودة في [mobile/README.md](./mobile/README.md). لا تُرفع قاعدة بيانات الكمبيوتر أو صور الاستيكرات إلى هذا المستودع.
